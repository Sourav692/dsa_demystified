2013 · Detect Squares

Points keep arriving on a grid. For a query point, how many squares can it close?

The problem, in plain words

You build a small "point keeper" with two buttons. add drops a pin on a grid (the same spot can get several pins). count takes a new point and asks: how many ways can I pick three pins so that, with this point, they make a square with straight sides (horizontal and vertical) and a size bigger than zero?

Example: pins at (3,10), (11,2), (3,2). Query (11,10) → 1 square. Add a second pin at (11,2) and the same query gives 2: each copy of that pin makes its own square.

The blue "×2" next to a pin means two pins sit on that spot.

The key fact

Pick the pin diagonally opposite the query. That one pin fixes the whole square: the two other corners must be at (query x, pin y) and (pin x, query y). A pin is a diagonal partner only when it is as far away sideways as it is up or down (|dx| == |dy|) and not in the same column (dx != 0, else the square has no area).

Solution 1 — Brute force: keep a list, rescan it for each corner

Keep every pin in a plain list. For a query, try each pin as the diagonal partner. When one fits, walk the whole list again to count the pins on each of the two other corners, and multiply.

the list (every pin, duplicates kept)

squares so far (res)

Speed & memory: add is instant, O(1). But count may rescan the list once per diagonal pin: O(n²) per query. The notebook measured about 4× slower per doubling of the pins. Memory O(n).

Solution 2 — The smart way: count the pins in a map

When a pin is added, bump its tally in a map: cnt[(x, y)] += 1. For a query, loop over each distinct spot once. If it is a diagonal partner, the number of squares it makes is (pins here) × (pins on corner 1) × (pins on corner 2) — three instant map lookups, no rescans.

When you'd use this

See "duplicates count as different", "how many ways", or a stream of items with a question about how many of them fit a shape? Count the items in a hash map as they arrive, then answer by multiplying counts instead of searching.
