1448 · Count Good Nodes in Binary Tree

Walk down from the root. Count the nodes that are at least as big as everything above them.

The problem, in plain words

Picture a family tree where every person has a height. A person is good if nobody above them in their own line (parent, grandparent, and so on up to the root) is taller than them. Ties are fine. Count the good people.

Example: root = [3,1,4,5,null,1,5] has 4 good nodes: the root 3, the 4, and both leaves with value 5. The lower-left 5 is good because it is greater than both ancestors on its path, 3 → 1 → 5.

A path here means the chain of nodes from the root down to one node. Each node has exactly one.

Try it: check each node by hand

Go node by node, top level first. For each one, look at its path from the root and ask: is anything above it bigger?

Notice: to judge a node you only need the biggest value above it, not the whole path.

Solution 1 — Re-check the whole path at every node (brute force)

Walk the tree with DFS (go deep down one branch, then back up and try the next). Keep a list of the values on the way down. At each node, scan that whole list: if nothing in it is bigger, the node is good.

path list (values above the current node)

Speed & memory: every node re-reads its whole path, so a tall tree gets slow fast: O(n·h) time (O(n²) for a chain), O(h) memory for the path list and the calls.

Solution 2 — DFS that carries the path's max (optimal)

Instead of the whole path, hand each child one number: max_so_far, the biggest value above it. A node is good if node.val >= max_so_far. It passes max(max_so_far, node.val) down to its children, and returns good + left count + right count back up.

call stack (open calls, root first)

Speed & memory: one quick check per node, so O(n) time. The open calls form one root-to-node path, so O(h) memory.

When you'd use this

See "on the path from the root", "no ancestor bigger than", or "compared with every node above it"? Run one DFS and pass a small summary of the path (a max, a min, a sum) down as an argument.
