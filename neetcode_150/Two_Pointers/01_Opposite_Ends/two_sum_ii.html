167 · Two Sum II - Input Array Is Sorted

A sorted list, a target, and two fingers that squeeze in from the ends.

The problem, in plain words

The numbers are already in order, smallest to largest. Find the two that add up to the target and give their positions, counting from 1 (not 0). There is exactly one such pair. You may only use a couple of extra variables, no extra lists or maps.

Example: [1, 3, 4, 5, 7, 10, 11], target 9 → [3, 4], because the 3rd number (4) plus the 4th number (5) is 9.

Solution 1 — Brute force: try every pair

Hold the first number, try it with every number after it. Then hold the second number, and so on. Stop at the first pair that adds up to the target.

Speed & memory: checks up to every pair, so doubling the list makes it about 4× slower — O(n²) time, O(1) memory. It never uses the fact that the list is sorted.

Solution 2 — Hash map: remember what you have seen

The trick from the original Two Sum. Walk left to right. For each number, ask "have I already seen the partner that makes 9?" A hash map (a lookup table that finds a key in one step) answers instantly. It works, but it ignores the sorted order and uses extra memory the problem does not allow.

seen (value → index)

Speed & memory: one pass — O(n) time, but the map can grow to O(n) memory. Fast, yet it breaks the "constant extra space" rule.

Solution 3 — The smart way: two fingers from opposite ends

One finger on the smallest number (left end), one on the largest (right end). Add them. Too small? The left number can't reach 9 even with the biggest partner left, so drop it: move the left finger right. Too big? The right number overshoots even with the smallest partner left, so drop it: move the right finger left. Exactly 9? Done.

Speed & memory: every step drops one number for good, so at most n - 1 steps — O(n) time, O(1) memory (just two positions).

When you'd use this

See "sorted array" plus "find a pair that adds up to a target", especially with "constant extra space"? Put a finger at each end and let the sum tell you which finger to move.
