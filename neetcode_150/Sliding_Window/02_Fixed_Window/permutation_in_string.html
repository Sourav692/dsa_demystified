567 · Permutation in String

Is some scrambled copy of s1 hiding, letters side by side, inside s2?

The problem, in plain words

You have a short word s1 and a long text s2. Look for a block of s2, letters next to each other, that uses exactly the letters of s1, each the same number of times, in any order.

Think of Scrabble tiles: s1 is your rack. You win if some stretch of s2 could be spelled with exactly your tiles, no more and no fewer.
Example: s1 = "ab", s2 = "eidbaooo" → True, because the block "ba" uses one a and one b.

The answer must be exactly len(s1) = 2 letters long, so only blocks of that one width are worth checking.

Solution 1 — Brute force: sort every block

Sorting puts letters in order, so any rearrangement of "ab" sorts back to "ab". Cut out every block of width 2, sort it, and compare with sorted s1.

block, sorted, vs sorted(s1) = "ab"

Speed & memory: every block is copied and sorted from scratch — O(n·k log k) time for n = len(s2), k = len(s1); O(k) memory for one sorted copy.

Solution 2 — Better: count the letters of every block

Order never mattered, only how many of each letter. So count s1 once ({a:1, b:1}) and count each block. Same counts means same tiles. Still, each block is counted from zero, even though it shares a letter with the block before it.

Speed & memory: no sort, but every block is still recounted — O(n·k) time; at most 26 letters per counter.

Solution 3 — The smart way: slide a fixed window and update the counts

Moving the block one step right changes only two letters: one enters on the right (+1), one leaves on the left (-1). Keep a running count of the window and update just those two. Once the window is full (2 letters), compare it with s1's counts — 26 small numbers, a fixed cost.

Speed & memory: two count updates and one 26-slot compare per letter of s2 — O(n) time; two arrays of 26 numbers — O(1) memory.

When you'd use this

See "permutation" or "anagram" of a word inside a longer string, or "every substring of length k"? The answer has one fixed width, so slide a window of that width and keep counts up to date: one letter in, one letter out.
