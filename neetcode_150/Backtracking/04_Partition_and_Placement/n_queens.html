51 · N-Queens

Put n queens on an n × n chessboard so that no two can attack each other. List every way.

The problem, in plain words

A chess queen attacks along her row, her column, and both diagonals, as far as the board goes. Place n queens so that none of them is attacked. Return every such board, drawn as strings with Q for a queen and . for an empty square.

Example: n = 4 has exactly two answers: [".Q..","...Q","Q...","..Q."] and ["..Q.","Q...","...Q",".Q.."].
Two shortcuts: every row holds exactly one queen (two in a row would attack), and every square on one diagonal shares a number: r − c for a \ diagonal, r + c for a / diagonal.

Row and column numbers start at 0, top-left.

Solution 1 — Brute force: try every column order, then check diagonals

One queen per row and one per column means a board is just an ordering of the columns: perm[r] is the column of row r's queen. Try all n! orderings. Keep one if all r − c values differ and all r + c values differ (no shared diagonal).

r − c per row  ·  r + c per row

queenqueens sharing a diagonal

Speed & memory: all n! boards are built in full, even when the first two queens already clash — O(n · n!) time, O(n) extra memory. The notebook measures it growing roughly n× per extra row (5.7× at n = 6 up to 8.7× at n = 9).

Solution 2 — Backtracking: place row by row, scan the queens above

Fill row 0, then row 1, and so on. Before putting a queen on (r, c), look at every queen already placed: same column, or same diagonal (|row gap| == |column gap|), means unsafe. A safe square gets a queen and we move to the next row. A row with no safe square is a dead end: take back the last queen and try its next column.

Speed & memory: attacked squares are skipped before recursing, so far fewer than n! boards are explored; each check still scans up to n queens — O(n · n!) as an upper bound, O(n) memory. Measured: about 4–5× per extra row.

Solution 3 — The smart way: backtracking with three sets

Same search, faster check. Keep three sets: used columns cols, used \ diagonals diag (by r − c), used / diagonals anti (by r + c). "Is (r, c) safe?" is three instant lookups. Placing a queen adds three numbers; removing it takes the same three out.

cols  ·  diag (r − c)  ·  anti (r + c)

boards found

queenattacked (in a set)tried, blockedsquare just placed / removed

Speed & memory: the same pruned search, with O(1) checks — O(n!) upper bound, O(n²) memory for the working board. In the notebook it is the fastest of the three (about 5 ms at n = 9 against 130 ms for the brute force).
