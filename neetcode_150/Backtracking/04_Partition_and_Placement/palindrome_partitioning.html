131 · Palindrome Partitioning

Cut a string into pieces that each read the same both ways. List every way to do it.

The problem, in plain words

You have a word and a pair of scissors. You may cut between any two letters, as often as you like. A cut pattern is good when every piece is a palindrome (reads the same forwards and backwards, like "aa" or "aba"). Return every good cut pattern.

Example: "aab" → [["a","a","b"], ["aa","b"]]. Single letters are always palindromes, so cutting everywhere always works.
palindrome piecenot a palindromeblue bar = a cut

"aab" has 2 gaps, so there are only 4 ways to cut it. Two of them are good.

Solution 1 — Brute force: try every cut pattern, then check

Each gap is either cut or not, like a row of light switches. Count a number mask from 0 to 2gaps − 1 and read its bits as the switches. Build the pieces for that pattern, and keep it only if every piece is a palindrome.

mask bits (bit i = cut after letter i; bit 0 is on the right)

good patterns so far

Speed & memory: it builds all 2n−1 patterns no matter what, even when a bad piece shows up at the very start — O(n · 2^n) time, O(n) extra memory. The notebook measures about 2× per extra letter on every input.

Solution 2 — Backtracking: pick the next palindromic piece

Stand at index start. Try every possible next piece s[start:end]. If it is not a palindrome, skip it right away: nothing built on it can work. If it is, take it, solve the rest from end, then put it back and try a longer piece. Reaching the end of the string means the pieces in hand are one answer.

Solution 3 — Same backtracking, palindrome answers looked up in a table

First fill a small table: is_pal[i][j] says whether s[i..j] is a palindrome. A piece is a palindrome when its two end letters match and its inside is a palindrome, so fill the table from the bottom row up. Then run Solution 2, but each check is one lookup instead of reversing the piece.

When you'd use this

See "return all ways to split / partition / cut a string" where every piece must pass a test? Backtrack on where the next piece ends, and test each piece before recursing.
