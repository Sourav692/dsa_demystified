79 · Word Search

Can you spell the word by walking from letter to neighbouring letter, never stepping on the same square twice?

The problem, in plain words

You get a grid of letters and a word. Walk up, down, left or right from cell to cell. Can the letters you step on spell the word, using each cell at most once?

Think of a word-search puzzle where the word is allowed to bend around corners.

Approach 1 — Brute force: try every path, compare at the end

From every start cell, build every path of exactly len(word) neighbouring cells that never repeats a cell. Only when a path is complete, read its letters and compare them with the word. The letters never steer the search.

Sample: board [["A","B"],["C","D"]], word "BDC". Watch how it builds two full paths from A even though the word starts with B.

Speed & memory: every path of length L from every cell, each copied and joined: O(rows·cols·3^L·L) time, O(L) memory. It does the same work whatever the letters are.

Approach 2 — Backtracking DFS: prune, mark, restore

Grow one path, letter by letter. A call dfs(r, c, i) asks "can the word from letter i on start at cell (r, c)?". If the cell is off the board or holds the wrong letter, stop at once (prune). Otherwise mark it # so this path can't step on it again, try the 4 neighbours for the next letter, then restore the letter on the way back so other paths can use the cell.

Sample: the LeetCode board, word "ABCCED". Neighbours are tried in the code's order: down, up, right, left.

Speed & memory: worst case O(rows·cols·3^L) (a board of all one letter), but a wrong letter ends a path after one step, so ordinary boards finish far sooner. O(L) memory: just the recursion; the mark lives in the board.

When you'd use this

See "find a word / path in a grid, each cell used once"? That is grid backtracking: DFS from every cell, mark the cell, explore its neighbours, restore it.

Not the same as flood fill (Number of Islands): there a visited cell stays visited for good. Here the mark is undone on the way back, because a different path may need that cell.
