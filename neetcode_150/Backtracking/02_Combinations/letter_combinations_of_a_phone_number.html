17 · Letter Combinations of a Phone Number

Every word a digit string can spell on a phone keypad.

The problem, in plain words

On an old phone keypad each digit key also has letters (2 = abc, 3 = def, ..., 7 = pqrs, 9 = wxyz). Given some digits, list every word you could type by choosing one letter per key, in order.

Example: "23" → ["ad", "ae", "af", "bd", "be", "bf", "cd", "ce", "cf"]. Empty input → [].

words

Both solutions are traced on "23". They do the same amount of work: the output itself has up to 4^n words.

Solution 1 — Grow every prefix, one digit at a time

Start with one empty prefix. For each digit, make a new list: every prefix you have, extended by every letter of that digit. After the last digit the list is the answer. This builds the tree level by level.

combos (previous round)

new list being built

Speed & memory: O(n · 4^n) time; it keeps a whole level of prefixes while building the next one, O(n · 4^(n-1)) extra memory. (In Python the list comprehension is quick: the notebook's benchmark shows it a few times faster than Solution 2, with the same growth.)

Solution 2 — The pattern template: backtracking, one digit per level

Walk the same tree depth-first. Level i chooses a letter for digits[i]: append it, recurse to level i + 1, pop it. When the path has one letter per digit, save it. The level number plays the role of the start index, so nothing can repeat.
