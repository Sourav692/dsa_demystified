22 · Generate Parentheses

Every balanced arrangement of n bracket pairs.

The problem, in plain words

Given n, write down every way to arrange n opening and n closing brackets so that they match up properly.

Example: n = 3 → ["((()))", "(()())", "(())()", "()(())", "()()()"].
NeetCode lists this problem under Stack, because checking brackets is a stack job. Producing all of them is a backtracking build, so here it lives in the Combinations pattern.

Solution 1 — Brute force: build every bracket string, then check it

Put either ( or ) in every position: 22n strings. Check each with a running balance (+1 for (, −1 for )): it must never go below 0 and must end at 0. Keep the ones that pass. Traced on n = 2 to keep the list short.

Speed & memory: O(4^n · n) time: 4^n strings, each checked in O(n); O(n) depth. Most of the work is thrown away (14 of 16 here).

Solution 2 — The pattern template: backtracking with open/close counts

Build the string one bracket at a time, and only make moves that keep it fixable: add ( while open < n; add ) only while close < open. Then every string that reaches length 2n is balanced, so nothing is ever thrown away.

Speed & memory: proportional to the number of answers (the Catalan number, about 4^n / n^1.5) times n to build each: O(4^n / √n) time, O(n) depth. Here: 22 calls for 5 answers (the brute force would build 64 strings for n = 3).
