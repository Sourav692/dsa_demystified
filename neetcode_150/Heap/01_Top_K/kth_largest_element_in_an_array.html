215 · Kth Largest Element in an Array

Find the value that would be in k-th place if the array were sorted, best first.

The problem, in plain words

You have a list of numbers and a number k. Imagine lining the numbers up from biggest to smallest; return the one standing in place k. Duplicates each take their own place. The challenge: can you do it without sorting the whole list?

Example: nums = [3, 2, 1, 5, 6, 4], k = 2 → 5 (biggest first: 6, 5, 4, 3, 2, 1).

"k-th largest" is the same as index n - k once the list is sorted smallest first: here 6 - 2 = 4.

Solution 1 — Brute force: sort, then count back k

Sort the list smallest first and read the value k places from the end.

Speed & memory: a full sort — O(n log n) time, O(n) memory for the sorted copy. (In Python, sorted runs in C, so it is often the fastest in practice; the notebook's timings show it.)

Solution 2 — The pattern: a min-heap that keeps only the top k

Keep a small pile of the k biggest numbers seen so far, smallest of them on top (a min-heap). Push each number; if the pile now has k + 1, the top one leaves. When the list is done, the top of the pile is the k-th largest.

Speed & memory: one push and at most one pop per number on a pile of size k + 1 — O(n log k) time, O(k) memory.

Solution 3 — Quickselect: split around a random pivot, keep one side

Pick a random pivot. Rearrange the range into three blocks: smaller than the pivot, equal to it, bigger than it. The equal block is now in its final sorted place. If the target index n - k is inside it, the pivot is the answer; otherwise repeat on only the side that holds the target. Pointers: everything left of lt is smaller, i is the value being checked, everything right of gt is bigger.

Speed & memory: each round scans the current range once and keeps about half — O(n) on average (O(n²) only if the pivots are very unlucky). The notebook copies the list first (O(n)); in place it needs O(1) extra. The pivots below are the ones the notebook's seeded random generator picks on this input: 3, then 5.

When you'd use this

See "k-th largest" or "top k"? The size-k min-heap is the safe default (and the only choice for a stream). If the whole array is in memory and you may reorder it, quickselect gets O(n) on average.
